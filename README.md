# InterviewX

AI-powered virtual human interview simulation platform.

## Current status

**Task 01:** Hybrid Luxury login page (UI + client validation). Authentication backend is not wired yet.

## Run the web app

```bash
cd apps/web
npm install
npm run dev
```

Open [http://localhost:3000/login](http://localhost:3000/login) (root `/` redirects to `/login`).

## Scripts

```bash
cd apps/web
npm run lint
npx tsc --noEmit
npm run build
```
